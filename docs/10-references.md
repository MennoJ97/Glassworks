# References

These are the sources cited in the chapters. To read further, start with
[Strang & Fix](#strang-fix-2008) for FEM theory, [Jin](#jin-2014) for FEM in
electromagnetics and [Parlett](#parlett-1998) for Lanczos.

## Software

- [`faer`](https://docs.rs/faer): the Rust linear algebra library used in this project's tests.
- [MFEM](https://mfem.org): the finite element library described in [Anderson et al. 2021](#anderson-2021).
- [Palace](https://github.com/awslabs/palace): a 3D electromagnetics solver built on MFEM.
- [Triangle](https://www.cs.cmu.edu/~quake/triangle.html): the mesh generator described in [Shewchuk 1996](#shewchuk-1996).
